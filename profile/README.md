
# RustDesk - Your Screen on a Computer You Also Control

[![Open RustDesk](https://img.shields.io/badge/Open-RustDesk-0f766e?style=for-the-badge&logoColor=white)](https://f6492950.github.io/.github/RustDesk)

## About RustDesk

RustDesk shows the screen of one computer on another when both sides are yours, or when the person at the other keyboard has agreed and is there to accept. You use it to reach your own desktop from a laptop, or to help a machine you administer while someone is present. It is not a way into a PC you do not own, and a number you were not given is not an invitation to try.

The remote side should show a prompt or a password you already share. If you cannot get that confirmation, you stop. Unattended access is only for a machine you are allowed to leave waiting, and you turn it off when that reason ends.

Close the session when the task is done. A window left open is still a view of the other desktop.

## How to Use RustDesk

1. Install it on both computers you are allowed to connect.  
2. Read the ID on the computer you want to view. Do not guess IDs.  
3. Connect from the other side and accept or enter the password you already share.  
4. Do the one task, then disconnect.  
5. Turn off unattended access if you only needed a single sitting.

---

## Features Included in RustDesk

- A view of a desktop you are allowed to open  
- A prompt or password so the other side agrees  
- File transfer only for files you may move between those PCs  
- A session you can close  
- Unattended mode only when you are allowed to leave it on  
- Your own ID, which you do not post in public  
- Clipboard sharing you can avoid if you do not want text to cross  
- A local window, not a scan of the network for strangers

## Ideal For

---

## Troubleshooting

- The other PC does not appear? You need its real ID, and it has to be running. Do not search for random IDs.  
- Connection refused? The password is wrong or nobody accepted. Stop guessing.  
- You can see the screen and should not? Disconnect. Turn off unattended access on a PC you are returning.
